# `vec`

The `vec` keyword is a primitive vector type keyword. It denotes a growable, contiguous sequence type used for collections of values.

---

## Syntax & Example

```adesh
let nums: vec<i32> = [1, 2, 3];
let empty: vec<u8> = [];
```

---

## Use Cases

- Storing a growable, ordered sequence of values.
- Annotating collection-typed parameters and return types.
- Pairing with array literals and collection operations.
